# Funksiyalar va holati

- Kontaktlar kitobi, tahrirlash uchun o‘chirish/qayta qo‘shish, tug‘ilgan sana va Telegram ID
- Rejalashtirilgan matnli, rasmli, videoli yoki GIF tabriklar
- Tabriklar ro‘yxati va bekor qilish
- O‘zbek/rus/ingliz til tanlovi
- Shaxsiy statistika, admin statistikasi
- CSV kontakt eksporti
- Admin uchun SQLite backup
- Yetkazish jurnali va qayta urinishlar
- Docker/systemd deploy namunalari

Eslatma: guruhga ommaviy tabrik, kontaktni inline tahrirlash, vaqt zonasi foydalanuvchi bo‘yicha sozlash va avtomatik yillik tabrik/oldindan eslatmalar to‘liq UI bilan hali kiritilmagan. Bu funksiyalarni README’da ochiq ko‘rsatdik, ular tayyor deb da’vo qilinmaydi.
